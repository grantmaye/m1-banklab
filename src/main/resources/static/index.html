What this lab demonstrates

Spring validates requests, locks account rows in a consistent order, and commits balances, the journal, fraud assessments, and audit records in one PostgreSQL transaction. Insufficient-funds transfers return 422 without a journal entry. Fraud scores explain risk after posting; they do not block transfers.

The service permits all requests and disables CSRF. Keep it on localhost with invented data. It has no account ownership enforcement, real settlement, or replay protection. The desk only selects the three seeded accounts; other API workflows remain in the API reference.
